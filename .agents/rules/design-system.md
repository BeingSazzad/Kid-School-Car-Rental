# Home2School Design System Memory & Guidelines

## Locked Color Palette (DO NOT CHANGE)
- **Primary**: `#1B2B68` (Deep Royal Navy - parental trust, security, stability)
- **Secondary**: `#F2600C` (Vibrant Brand Orange - safety, high-visibility, warmth)
- **Fade**: `#F0F3FA` (Soft surface - inputs, cards, date blocks)
- **Title**: `#1A1D24` (High-contrast obsidian text - headings, titles, labels)
- **Body**: `#6B7280` (Muted neutral slate gray - subtext, descriptions)
- **Stroke**: `#ECECF0` (Clean subtle border - inputs, card dividers)

## Layout & Viewport Rules
- Target mobile screen width: `430px` (centered on desktop, 100% fluid on mobile).
- Horizontal padding/margin: exactly `20px` on both sides (`390px` usable width).
- Do NOT wrap in heavy phone mockups, borders, or desktop switchers. Render clean direct mobile web container.
- All primary buttons: `height: 48px;`, `font-size: 18px;`, `font-weight: 800;` (ExtraBold), `border-radius: 12px;`.
- Font: **Manrope** from Google Fonts.

## Iconography Standard
- Use standard Lucide vector icons (`stroke-width: 2.0` to `2.6`, `stroke-linecap="round"`, `stroke-linejoin="round"`).
